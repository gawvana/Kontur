# Инструкции по эксплуатации («Контур»)

## Локальный запуск
1. Склонируйте репозиторий.
2. Скопируйте `.env.example` в `.env` и заполните конфигурацию.
3. Выполните запуск всего стека:
   ```bash
   docker-compose up -d --build
   ```
4. Примените миграции:
   ```bash
   docker-compose exec api alembic upgrade head
   ```

## Развёртывание
Для продакшена используйте Docker Swarm / Kubernetes или VPS с docker-compose.
Убедитесь, что закрыт доступ к Redis и БД извне.

## Команды бота
Инициализация бота: настроить вебхук в Telegram или использовать polling (по умолчанию).
```bash
# Получение статуса бота
docker-compose logs -f bot
```
