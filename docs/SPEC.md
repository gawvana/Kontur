# Спецификация проекта «Контур»

## 1. Описание
«Контур» — Telegram-антискам-сервис с Mini App, ботом и закрытой админ-панелью. Сервис предназначен для проверки репутации аккаунтов, ведения приватных/совместных каталогов контактов и рассмотрения обращений (как положительных, так и отрицательных).

## 2. Роли
- **Пользователь (User)**: может искать контакты, вести каталоги, оставлять отзывы, подавать апелляции.
- **Владелец/Редактор/Читатель каталога**: локальные роли в рамках совместных каталогов.
- **Модератор (Moderator)**: рассматривает обращения, проверяет доказательства. Не имеет доступа к чужим личным заметкам.
- **Старший модератор / Апелляционный сотрудник (Senior Moderator)**: рассматривает апелляции на решения обычных модераторов.
- **Администратор (Admin)**: управляет пользователями, политиками, ролями.
- **Владелец (Owner)**: имеет полный доступ к настройкам системы.

## 3. Основные продуктовые правила
1. Личные каталоги, заметки, вложения и оценки приватны по умолчанию.
2. Публичные плюсы и минусы проходят модерацию.
3. Отзыв основан на опыте взаимодействия, а не на слухах.
4. Отсутствие автоматического ярлыка «мошенник» за число голосов.
5. Подтверждение аккаунта — это только подтверждение доступа к TG-аккаунту.
6. Защита от накруток, продажных удалений отзывов.
7. Редактирование публичного текста/оценки требует перепроверки модератором.

## 4. Категории взаимодействий
- Товар
- Цифровой результат
- Услуга
- Обмен
- Другое

## 5. Доказательства
- Допустимые форматы: JPEG, PNG, WebP, PDF, MP4, WebM, OGG, MP3.
- Лимиты: до 20 файлов / 100МБ на обращение.
- Процесс обработки: загрузка -> карантин -> проверка (MIME, размер) -> изоляция/обработка -> безопасная копия.
