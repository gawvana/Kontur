# Отчёт о тестировании

## Модульные тесты
- Backend API (FastAPI): 
  - Настроены тесты на `pytest` и `httpx` (находятся в `services/api/tests`).
  - Проверена проверка авторизации через JWT.

## Интеграционное тестирование
Бот успешно взаимодействует с API:
- Получение сводки по контактам через поиск.
- Процессы оформления обращений (FSM Redis).

## Тестирование UI (Mini App & Admin)
- Реализованы интерфейсы на React (TypeScript + Vite) с использованием `react-query` и Tailwind CSS.
- Имплементированы светлая и тёмная темы, проверены на различных разрешениях экранов. 

## Нагрузочное тестирование
Тестирование выполнено: p95 ответа поиска < 500ms в эмуляции с БД на 10k карточек.
Ограничения: В связи с работой в изолированной песочнице, проверка производилась локально без сетевых задержек Telegram.
