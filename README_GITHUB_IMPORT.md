# Контур: исходники для GitHub

Этот пакет — проверенная исходная версия из Kontur(1).zip, а не исправленный релиз. Приложение пока не готово к production. В текущих старых документах имеются неподтверждённые заявления о полной готовности; актуальный независимый аудит находится в docs/NEW_VERSION_INDEPENDENT_AUDIT.md и HTML.

Удалены зависимости, Windows virtualenv, кеши, Git-объекты и тестовые БД. Пользовательские данные в исходном архиве не изменялись. В пакет добавлены актуальный аудит и полный промт Codex. При загрузке папка проекта должна стать корнем репозитория, а не вложенной папкой Kontur/Kontur.

## Задание для Codex

Открой docs/CODEX_FULL_REPAIR_PROMPT.md и выполни его целиком. Начни с текущего состояния репозитория и независимого аудита, закрой N01–N32, реализуй недостающие процессы и подготовь проверяемый деплой Vercel + INFRLO + Supabase. Не объявляй production готовым по одной сборке. Записывай прогресс и блокеры в docs/WORKLOG.md.

## Конфигурация

Настоящие BOT_TOKEN, JWT secret, доступы БД и storage задаются вне Git. .env.example содержит пример. Не добавляй .env, БД, venv, node_modules или доказательства пользователей в коммиты.

Загрузка исходников на GitHub сама по себе не запускает API, бот или Mini App. Перед публикацией приложения нужны исправления и live приёмка из аудита.
